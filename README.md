When Hands Talk
Real-Time Hand Sign Alphabet Recognition System
Project Overview

When Hands Talk is a real-time hand sign recognition system developed to recognize hand sign alphabets using a webcam. The project focuses on building a practical gesture recognition pipeline that converts hand signs into readable text in real time.

The system uses MediaPipe for hand landmark detection and a Support Vector Machine (SVM) classifier built with Scikit-learn to classify gestures. The project covers the complete workflow including data collection, model training, and live prediction, demonstrating the use of computer vision and machine learning in an assistive communication application.

Objectives

Enable real-time recognition of hand sign alphabets

Explore assistive communication using gesture recognition

Build a modular pipeline for data collection, training, and deployment

Apply computer vision and machine learning concepts in a real-time system

Key Features

Real-time hand tracking using webcam input

Alphabet-level hand sign recognition

Gesture classification using an SVM model

Custom dataset collection and training pipeline

Modular and extensible project structure

Lightweight implementation runnable on a standard laptop
